# Domrei-Runtimes

Official runtime and renderer asset repository for **Domrei Launcher** (`com.domrei.gameengine`):

- **OpenJDK Runtimes** (`runtimes/jre-8`, `runtimes/jre-17`, `runtimes/jre-21`, `runtimes/jre-25`) for `arm64-v8a`, `armeabi-v7a`, `x86_64`, and `x86`
- **Renderers & Audio** (`libs/MobileGlues-release.aar`, `libs/NG-GL4ES-release.aar`, `libs/lwjgl-3.3.3-natives-release.aar`, `libs/openal-soft-release.aar`)
- **Android LWJGL 3.3.3 Jars** (`app_runtime/lwjgl/3.3.3/`)
- **Android JNA 5.17.0 Natives** (`runtimes/jna/5.17.0/natives/`)
